# 💱 Currency Converter Application

A web-based Currency Converter application developed using Flask that converts one currency to another using real-time or static exchange rates.

---

## 📌 Project Overview

The Currency Converter allows users to select source and target currencies and enter an amount.  
The application calculates and displays the converted value instantly.

---

## 🛠️ Technologies Used

- Python (Flask)
- HTML5
- CSS3
- Bootstrap
- JavaScript
- External Currency Exchange API (optional)

---

## 🚀 Features

- Convert between multiple currencies
- Real-time exchange rate support
- Simple and intuitive user interface
- Instant conversion results
- Error handling for invalid inputs
